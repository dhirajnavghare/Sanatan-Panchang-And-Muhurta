================================================================================
                    SANATAN PANCHANG & MUHURTA (ANDROID)
================================================================================

--------------------------------------------------------------------------------
1. ONE-TIME ENVIRONMENT SETUP (Mac ZSH)
--------------------------------------------------------------------------------
Run these once in your terminal so `adb` and Android SDK are recognized globally:

echo 'export ANDROID_HOME=$HOME/Library/Android/sdk' >> ~/.zshrc
echo 'export PATH=$PATH:$ANDROID_HOME/platform-tools:$ANDROID_HOME/emulator' >> ~/.zshrc
source ~/.zshrc

Verify setup:
adb devices


--------------------------------------------------------------------------------
2. LOCAL DEVELOPMENT (Metro Server & Fast Refresh)
--------------------------------------------------------------------------------
From project root (`sanatan.cc.react.native`):

# Start development server
npm start

# Or directly run on active Android emulator / connected device
npx expo run:android

# Useful development checks
npx tsc --noEmit       # TypeScript type checking
npx expo-doctor        # Check project health & dependencies


--------------------------------------------------------------------------------
3. BUILD RELEASE APK (For Testing on Physical Device or Emulator)
--------------------------------------------------------------------------------
From project root:

cd android
./gradlew :app:assembleRelease

Output APK:
android/app/build/outputs/apk/release/app-release.apk


--------------------------------------------------------------------------------
4. INSTALL & RUN RELEASE APK ON EMULATOR / DEVICE
--------------------------------------------------------------------------------
If you are inside the `android/` directory:
adb install -r app/build/outputs/apk/release/app-release.apk && adb shell monkey -p cc.sanatan.app -c android.intent.category.LAUNCHER 1

If you are in the project root (`sanatan.cc.react.native`):
adb install -r android/app/build/outputs/apk/release/app-release.apk && adb shell monkey -p cc.sanatan.app -c android.intent.category.LAUNCHER 1


--------------------------------------------------------------------------------
5. BUILD SIGNED ANDROID APP BUNDLE (.AAB) (For Google Play Console)
--------------------------------------------------------------------------------
From project root:

cd android
./gradlew :app:bundleRelease

Output AAB:
android/app/build/outputs/bundle/release/app-release.aab

Verify signature on generated bundle:
jarsigner -verify -verbose -certs app/build/outputs/bundle/release/app-release.aab | grep -i "CN=Sanatan"


--------------------------------------------------------------------------------
6. QUICK RE-PREBUILD (If regenerating native folders)
--------------------------------------------------------------------------------
From project root:

npx expo prebuild --platform android
# Ensure android/local.properties contains:
# sdk.dir=/Users/dhirajnavghare/Library/Android/sdk
