# Security Policy

## Supported Versions

We provide security updates and patches for the current release of Sanatan:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

The safety and privacy of our devotees and users is paramount. Since Sanatan operates **100% offline with zero external network requests and zero user data transmission**, the attack surface is minimal. However, we take all potential vulnerabilities seriously (e.g. local storage integrity, dependency vulnerabilities, or bundle tampering).

If you discover a potential security vulnerability, please follow these steps:

1. **Do not create a public GitHub issue.**
2. Send an email to the repository owner or use GitHub Private Vulnerability Reporting under the **Security** tab of the repository.
3. Include:
   - Description of the issue
   - Reproduction steps or proof-of-concept
   - Potential impact
4. We will acknowledge receipt within 48 hours and work with you on a coordinated disclosure and patch release.
