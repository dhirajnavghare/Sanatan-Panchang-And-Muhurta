# UI Inventory, Tour Architecture & Test Traceability Matrix

## 1. Application Architecture Overview

- **Framework & SDK**: Expo SDK 58 (`~58.0.26`), React Native `0.88.1`, React `19.3.0`, Expo Router `~58.0.32` (file-based routes under `app/`).
- **Navigation Shell**:
  - Root Stack (`app/_layout.tsx`): Loads fonts, initializes `LanguageProvider`, `TourProvider`, `ThemeProvider`, hosts `(tabs)`, `modal`, `+not-found`, `InteractiveTourOverlay`, and `ContextualHelpModal`.
  - Bottom Tabs (`app/(tabs)/_layout.tsx`): 7 tabs — Dinacharya (`index.tsx`), Muhurta (`muhurta.tsx`), Festivals (`festivals.tsx`), Prayers (`prayers.tsx`), More (`more.tsx`), Community (`community.tsx`), Settings (`settings.tsx`).
- **State, Persistence & Services**:
  - Offline ephemeris & astronomy: `src/core/panchang/*`, `src/core/festivals/*`, `src/core/muhurta-finder/*`.
  - User state & notifications: `src/services/userProfile.ts`, `src/services/sadhana.ts`, `src/services/dayplanner.ts`, `src/services/sacredNotifications.ts`, `src/services/sacredAudio.ts`, `src/services/vratGuidelines.ts`, `src/services/vratParana.ts`.
  - Community Hub network client: `src/services/projectApi.ts` (`ProjectApiError` handling `OFFLINE_OR_TIMEOUT`, `HTTP_ERROR`, `INVALID_RESPONSE`).
  - Guided Tour Engine: `src/services/appTour.ts`, `src/services/appTourContext.tsx`, `src/constants/tourSteps.ts`, `src/hooks/useTourScroll.ts`, `src/utils/tourSpotlight.ts`, `src/components/TourTarget.tsx`, `src/components/AppTourModal.tsx`, `src/components/InteractiveTourOverlay.tsx`, `src/components/ContextualHelpModal.tsx`.
- **Visual Design System**: Centralized dark/light tokens & `MIN_TOUCH_TARGET = 44` in `src/utils/theme.ts` (`getAppTheme`, `displayProfileName`), paired with `constants/Colors.ts`.

## 3. Quality Gate & Verification Architecture

| Check | Command | Purpose |
| :--- | :--- | :--- |
| Static Types | `npm run typecheck` | Zero-error TypeScript (`tsc --noEmit`) across `app/`, `src/`, `components/`, and `__tests__/`. |
| Strict Linting | `npm run lint:strict` | `eslint . --max-warnings=0` enforcing zero hook/import/unused-var errors or warnings. |
| Repository Guard | `npm run check:quality` | `scripts/check-project-quality.js`: checks `app.json`/`android/app/build.gradle`/`package.json` parity, `eas.json` profiles, 32-step tour target wiring, 8-section coverage, zero `.skip`/`|| true`/secret patterns, and >= 10 visual baselines. |
| Full Suite & Coverage | `npm run test:ci` | Runs all 35 Jest suites (unit, component, screen, negative/a11y, Expo Router multi-tab E2E, visual regression) enforcing global (`>= 80%` statements/lines) and core domain (`>= 90%` statements/lines) thresholds. |
| Bundle & Config Build | `npm run build:validate` | Validates `npx expo config --type public` and exports Android release JS bundle via `npx expo export --platform android` before cleaning temp artifacts. |
| Combined Quality Gate | `npm run quality` | Runs all 5 stages sequentially with fail-fast exit behavior in CI (`.github/workflows/ci.yml`). |
